Buenos Días. Tardes, Noches, o la hora en la que estes leyendo, este proyecto fue realizado por 2 estudiantes universitarios, 
fue bastante divertido, el poder conocer más sobre el arduino y donde puede llegar este mismo, además, los cosdigos de las visuales 
se deben usar en el pagina web Hydra, es bastante amigable para nuevos usauarios, si les gustaría replicar el proyecto, estos fueron los materiales 
1x Arduino Leonardo (ATmega32u4)

1x Módulo o circuito sensor con amplificador operacional LM358

1x Placa de pruebas (Protoboard)

4x Diodos LED (para el indicador visual físico)

1x Set de cables de conexión (Jumpers M/M y M/H)

1x Cable USB (para conexión y alimentación)

2x Pinzas de contacto o electrodos (para conectar a la planta)

dentro de los demás archivos podrán encontrar los codigos que logramos crear y utilizamos para que este proyecto funcione sin problemas
